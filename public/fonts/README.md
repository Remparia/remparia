# Fonts (licensed files)

Place self-hosted files here (woff2 preferred):

## UI — SF Pro Display
`public/fonts/sf-pro-display/`
- SF-Pro-Display-Regular.woff2
- SF-Pro-Display-Medium.woff2
- SF-Pro-Display-Semibold.woff2
- SF-Pro-Display-Bold.woff2
- SF-Pro-Display-Heavy.woff2
- SF-Pro-Display-Black.woff2

On Apple devices, the system SF Pro Display is used via `local()` even without these files.

## Headlines — Stolzl
`public/fonts/stolzl/`
- Stolzl-Book.woff2 (or Stolzl-Regular.woff2)
- Stolzl-Medium.woff2
- Stolzl-Bold.woff2
- Stolzl-Black.woff2
