# Studio — page override

> Overrides `design-system/remparia/MASTER.md` for `/studio`.

## Intent

Studio is the **atelier** in the Remparia model: SIGNAL finds the value, Studio builds the AI workforce, OS runs it, Governance keeps control.

Sell composition, not a chatbot playground. Agents, skills, tools, knowledge, workflows and human gates are born governed.

## Structure

1. Hero (dark, split) — one H1, one claim, builder canvas
2. Constat — playground vs atelier (`ph-compare`)
3. Couches — six building blocks, selectable
4. Protocole — how a workforce is composed
5. Force de travail — specialized agents
6. En action — one mission through the atelier
7. Gouverné dès la conception — identity, policies, audit, human gates
8. Trajectoire — SIGNAL → Studio → OS
9. Lime CTA band

## Rules

- Canonical shell: `Premium*` + `ph-*` tokens
- Companion CSS only: `studio-page.css` (`.st-*`), no new design language
- Cards black, 12px gap, 16px radius on dark; lime ≤ ~10%
- Buttons stay pills (`--btn-radius`)
- No emoji icons, no purple glow, no glassmorphism
- Interactive layers: border/background only, no layout-shifting hover
- Alternate dark → light → dark; final CTA is lime
