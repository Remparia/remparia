# Sovereignty — page override

> Overrides `design-system/remparia/MASTER.md` for `/sovereignty`.

## Intent

Sovereignty is a **deployment perimeter**, not a parallel product. SIGNAL finds the value, Studio builds the workforce, OS runs it, Governance keeps control — the same stack runs in Remparia Cloud, sovereign cloud, or on-premise.

Sell perimeter choice without watering down control. Hosting is decided; ALLOW / REVIEW / BLOCK, the log and human stops are not renegotiated per cloud.

Sovereignty is a **spectrum**: start in cloud, harden to sovereign / on-prem without changing agents or policies. Differentiator vs infra-only vendors: same AI workforce + same governance across modes.
