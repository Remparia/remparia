# Governance — page override

> Overrides `design-system/remparia/MASTER.md` for `/governance`.

## Intent

Governance is the **control layer** in the Remparia model: SIGNAL finds the value, Studio builds the workforce, OS runs it, Governance keeps every action under human-defined rules.

Sell **safe adoption that speeds teams up** — not a PDF policy, not compliance theater. Identity, permissions, ALLOW / REVIEW / BLOCK, budgets, observability and auditable logs live in the OS before the agent touches a customer.

## Structure

1. Hero (dark, split) — adoption-safe claim, live policy panel
2. Pourquoi maintenant — risk before policy (builders, personal logins, five ways, no gate)
3. Constat — shadow AI vs governed AI (`ph-compare`)
4. Les rails — control in the work (6 product rails, not consulting deliverables)
5. Délégation — green / amber / red heatmap (semantic only)
6. Piliers — six control pillars, selectable
7. Politiques — ALLOW · REVIEW · BLOCK
8. Outcomes — faster / aligned / visible
9. En action — one mission through the control plane
10. Journal — auditable action log
11. Trajectoire — SIGNAL → Studio → OS → Gouvernance (+ sovereignty note)
12. FAQ — short accordion
13. Lime CTA band

## Rules

- Canonical shell: `Premium*` + `ph-*` tokens
- Companion CSS only: `governance-page.css` (`.gv-*`)
- Cards black, 12px gap, 16px radius on dark; lime ≤ ~10%
- Heatmap uses semantic success / warning / danger — never brand blue
- Do not sell pricing retainers or certification badges
- Buttons stay pills (`--btn-radius`)
- No emoji icons, no purple glow, no glassmorphism
- Alternate dark → light → dark; final CTA is lime
